# UniXNU-t610yp

First-boot device repository for Unisoc UMS512 / T610YP (`sharkl5pro`).

Build from the `UniXNU` checkout, using this repository as the device
directory:

```sh
./unixnu defconfig t610yp_defconfig -D ../UniXNU-t610yp
./unixnu fetch
./unixnu build kernel
./unixnu build package
../UniXNU-t610yp/scripts/build-t610yp-uefi.sh ../edk2-sprd RELEASE
./unixnu build payload --uefi ../edk2-sprd
./unixnu bootimg --uefi ../edk2-sprd --dtb /path/to/t610yp.dtb
```

The UEFI wrapper is separate from the Unixnu kernel and payload steps because
`edk2-sprd` uses its native `CLANG38` build script rather than the Mu-Silicium
`CLANGPDB` firmware driver used by `uefi-sheng`.

The UEFI side is the existing `edk2-sprd` tree, whose board DSC is
`Platform/YEPEN/ums512/t610yp/t610yp.dsc`. This repository only supplies the
UniXNU board description, the source-kernel configuration and the Apple device
tree generator needed by DarwinBoot.

## Bring-up target

The first milestone is XNU entry with UART diagnostics. It deliberately does
not enable UFS, display, GPU, touch or Android userland. The supplied Linux FDT
(`t610w.dts`) is a hardware reference; it is not passed directly to XNU,
because XNU consumes the Apple-format ADT generated by
`scripts/make-t610yp-adt.py`.

The UMS512 firmware uses:

- GICv3 distributor `0x12000000`, redistributors `0x12040000`
- debug UART `0x70100000` (the FDT `/chosen/stdout-path`)
- hardware has two Cortex-A75 CPUs (`0x000`, `0x001`) and six Cortex-A55
  CPUs (`0x100` through `0x105`), all at 1.8 GHz; the ADT exposes all eight
  MPIDRs while using the A55-compatible CPU model for XNU bring-up
- DRAM base `0x80000000`; pass the actual installed size to the ADT tool

Build the ADT:

```sh
python3 scripts/make-t610yp-adt.py --dram-size 0x100000000 \
  --cpu-regs 0,0x1,0x100,0x101,0x102,0x103,0x104,0x105 \
  --output build/t610yp/boot/kernel.macho.adt
```

Build the T610YP firmware through the board wrapper. It invokes the native
`edk2-sprd` build and leaves the FD and BootShim outputs in that checkout:

```sh
scripts/build-t610yp-uefi.sh ../edk2-sprd RELEASE
```

The source-kernel and driver commands use the Apple/XNU inputs and toolchain
documented by the parent `UniXNU` checkout. When wrapping an Android boot
image, use the resulting FD and the compiled FDT from `t610w.dts`.

Capture UART at 115200 8N1. The firmware's debug port and the FDT's
`stdout-path` both select `0x70100000`.
